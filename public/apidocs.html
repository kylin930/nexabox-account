一、 认证与基础说明

所有的 API 请求基础路径为：/api

除登录接口外，所有请求都必须在 HTTP Header 中携带身份验证令牌：

Authorization: Bearer <你的_Token>

二、 用户基础接口

接口名称 请求方式 请求路径 说明
1. 用户登录 POST /api/login 验证用户名和密码，返回会话 Token。
请求体 (JSON): 
{"username": "your_name", "password": "your_password"}
成功响应 (200 OK): 
{"success": true, "token": "xxx-xxx", "isInitial": false, "permissions": ["Wiki"], "username": "your_name"}

接口名称 请求方式 请求路径 说明
2. 获取个人信息 GET /api/me 获取当前 Token 对应用户的详细信息。

接口名称 请求方式 请求路径 说明
3. 修改密码 POST /api/change-password 更新当前用户的密码（首次登录强制调用此接口）。
请求体 (JSON): 
{"newPassword": "my_new_password_123"}

三、 内部消息接口

接口名称 请求方式 请求路径 说明
1. 发送消息 POST /api/messages 向工作室的其他成员发送一条站内信。
请求体 (JSON): 
{"toUser": "target_username", "content": "Hello World!"}
2. 获取收件箱 GET /api/messages 获取发送给当前用户的所有消息。

四、 管理员专属接口

注意：以下接口仅限拥有 admin 权限的账户调用！

接口名称 请求方式 请求路径 说明
1. 创建新用户 POST /api/admin/users 录入新成员，分配初始密码。
请求体 (JSON): 
{"username": "new_guy", "initialPassword": "123456"}
2. 更新用户权限 PUT /api/admin/users/permissions 修改用户可访问的子系统列表。
请求体 (JSON): 
{"username": "new_guy", "permissions": ["DataBoard", "Wiki"]}
3. 删除用户 DELETE /api/admin/users 永久注销该用户账号。
请求体 (JSON): 
{"username": "user_to_delete"}
