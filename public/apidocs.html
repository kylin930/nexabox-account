Nexabox Account API 文档
基础说明

所有 API 请求的基础路径为：/api。除登录接口外，所有请求都必须在 HTTP Header 中携带身份验证令牌：

Authorization: Bearer <Your_Token>
用户认证
POST 用户登录
/api/login

请求体:

{
  "username": "your_name",
  "password": "your_password"
}

成功响应:

{
  "success": true, 
  "token": "uuid-token-string", 
  "isInitial": false, 
  "permissions": ["Wiki"], 
  "username": "your_name"
}
个人信息与设置
GET 获取个人信息
/api/me

成功响应:

{
  "username": "lisi",
  "permissions": ["all"],
  "avatar": "https://...",
  "lastLogin": 1716388492000
}
POST 修改密码
/api/change-password

请求体:

{ "newPassword": "my_new_password" }
子应用集成
POST 令牌验证
/api/verify

用于第三方或子应用验证 Token 有效性。

请求体:

{
  "token": "token_to_verify",
  "app": "AppName" // 可选，指定当前应用名称
}

成功响应:

{
  "valid": true,
  "username": "user_name",
  "permissions": ["DataBoard", "Wiki"],
  "has_all": false,
  "authorized": true // 仅当传了 app 参数时返回。如果有 'all' 权限，此项始终为 true
}
管理员接口

注意：以下接口仅限拥有管理员权限的账户调用！

POST 创建用户
/api/admin/users
{ "username": "new_guy", "initialPassword": "pwd" }
POST 一键全体赋权
/api/admin/users/grant-all

给系统内所有账户赋予指定权限。

{ "permission": "all" }
PUT 更新用户权限
/api/admin/users/permissions
{ "username": "guy", "permissions": ["Wiki"] }
